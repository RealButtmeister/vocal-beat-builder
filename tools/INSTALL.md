# Audio tools

This source repository does not distribute FFmpeg, Rubber Band, or their DLLs.
Obtain FFmpeg from https://ffmpeg.org/download.html and the Rubber Band command-line tools from https://breakfastquay.com/rubberband/ . Follow each project's license and installation instructions.

For the current Windows source, put `ffmpeg.exe`, `rubberband-r3.exe` and its required `sndfile.dll` beside this file. Keep the executable names as shown. Use 64-bit Windows builds. Rubber Band is required for pitch-preserving time stretching; FFmpeg handles formats that libsndfile cannot decode and full-song separation.

Existing upstream notices are retained here as dependency documentation; they do not license this application's original source. No executable or model is included in Git.
